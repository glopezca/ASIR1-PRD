# Ejercicios de scripting (PHP y Bash) — Variantes de entrada de datos

**Ciclo:** ASIR  
**Objetivo:** comprender las distintas formas de entrada de datos en scripts  
**Lenguajes:** PHP (CLI) y Bash  

Cada ejercicio se resuelve de **tres maneras**:

1. **Valores internos** (variables / constantes, sin entrada del usuario)  
2. **Entrada estándar interactiva** (STDIN)  
3. **Argumentos de la línea de comandos**  

---

## 📝 ENUNCIADOS

### Ejercicio 1. Contar valores
Mostrar cuántos valores se manejan en el script.

### Ejercicio 2. Listar valores
Mostrar todos los valores, uno por línea, indicando su posición.

### Ejercicio 3. Suma de números
Calcular la suma de varios números.

### Ejercicio 4. Pares e impares
Indicar si cada número es par o impar.

### Ejercicio 5. Buscar valor
Buscar un valor concreto dentro del conjunto.

---

## 🐘 SOLUCIONES EN PHP

### Ejercicio 1. Contar valores

#### Variante A — Variables internas
```php
<?php
$valores = [1, 2, 3, 4];
echo count($valores);
```
**Uso:** lógica interna / pruebas.

#### Variante B — Entrada estándar
```php
<?php
$linea = readline("Introduce valores separados por espacio: ");
$valores = explode(" ", trim($linea));
echo count($valores);
```
**Uso:** programas interactivos.

#### Variante C — Argumentos del script
```php
<?php
echo $argc - 1;
```
**Uso:** scripts no interactivos.

### Ejercicio 2. Listar valores

#### Variante A — Variables internas
```php
<?php
$valores = ["a", "b", "c"];
foreach ($valores as $i => $v) {
    echo "Pos $i: $v
";
}
```
#### Variante B — Entrada estándar
```php
<?php
$valores = explode(" ", readline());
foreach ($valores as $i => $v) {
    echo "Pos $i: $v
";
}
```
#### Variante C — Argumentos
```php
<?php
for ($i = 1; $i < $argc; $i++) {
    echo "Pos $i: {$argv[$i]}
";
}
```

### Ejercicio 3. Suma de números

#### Variante A — Variables internas
```php
<?php
$nums = [2, 4, 6];
echo array_sum($nums);
```
#### Variante B — Entrada estándar
```php
<?php
$nums = array_map('intval', explode(" ", readline()));
echo array_sum($nums);
```
#### Variante C — Argumentos
```php
<?php
$suma = 0;
for ($i = 1; $i < $argc; $i++) {
    $suma += (int)$argv[$i];
}
echo $suma;
```

### Ejercicio 4. Pares e impares

#### Variante A — Variables internas
```php
<?php
$nums = [1,2,3,4];
foreach ($nums as $n) {
    echo "$n " . ($n % 2 == 0 ? "par" : "impar") . "
";
}
```
#### Variante B — Entrada estándar
```php
<?php
$nums = array_map('intval', explode(" ", readline()));
foreach ($nums as $n) {
    echo "$n " . ($n % 2 == 0 ? "par" : "impar") . "
";
}
```
#### Variante C — Argumentos
```php
<?php
for ($i=1;$i<$argc;$i++) {
    $n=(int)$argv[$i];
    echo "$n " . ($n%2==0?"par":"impar") . "
";
}
```

### Ejercicio 5. Buscar valor

#### Variante A — Variables internas
```php
<?php
$buscar = "ana";
$datos = ["juan","ana","luis"];
echo in_array($buscar,$datos) ? "Encontrado" : "No encontrado";
```
#### Variante B — Entrada estándar
```php
<?php
$buscar = readline("Buscar: ");
$datos = explode(" ", readline("Datos: "));
echo in_array($buscar,$datos) ? "Encontrado" : "No encontrado";
```
#### Variante C — Argumentos
```php
<?php
$buscar = $argv[1];
for ($i=2;$i<$argc;$i++) {
    if ($argv[$i]===$buscar) { echo "Encontrado"; exit; }
}
echo "No encontrado";
```

## 🐧 SOLUCIONES EN BASH

### Ejercicio 1. Contar valores

#### Variante A — Variables internas
```bash
valores=(1 2 3 4)
echo "${#valores[@]}"
```

#### Variante B — Entrada estándar
```bash
read -a valores
echo "${#valores[@]}"
```

#### Variante C — Argumentos
```bash
echo "$#"
```

---

### Ejercicio 2. Listar valores

#### Variante A — Variables internas
```bash
valores=(a b c)
for i in "${!valores[@]}"; do
    echo "Pos $i: ${valores[$i]}"
done
```

#### Variante B — Entrada estándar
```bash
read -a valores
for i in "${!valores[@]}"; do
    echo "Pos $i: ${valores[$i]}"
done
```

#### Variante C — Argumentos
```bash
i=1
for arg in "$@"; do
    echo "Pos $i: $arg"
    ((i++))
done
```

### Ejercicio 3. Suma de números

#### Variante A — Variables internas
```bash
nums=(2 4 6)
suma=0
for n in "${nums[@]}"; do
    ((suma+=n))
done
echo "$suma"
```

#### Variante B — Entrada estándar
```bash
read -a nums
suma=0
for n in "${nums[@]}"; do
    ((suma+=n))
done
echo "$suma"
```

#### Variante C — Argumentos
```bash
suma=0
for n in "$@"; do
    ((suma+=n))
done
echo "$suma"
```

### Ejercicio 4. Pares e impares

#### Variante A — Variables internas
```bash
nums=(1 2 3 4)
for n in "${nums[@]}"; do
    (( n % 2 == 0 )) && echo "$n par" || echo "$n impar"
done
```

#### Variante B — Entrada estándar
```bash
read -a nums
for n in "${nums[@]}"; do
    (( n % 2 == 0 )) && echo "$n par" || echo "$n impar"
done
```

#### Variante C — Argumentos
```bash
for n in "$@"; do
    (( n % 2 == 0 )) && echo "$n par" || echo "$n impar"
done
```

### Ejercicio 5. Buscar valor

#### Variante A — Variables internas
```bash
buscar="ana"
datos=(juan ana luis)
for d in "${datos[@]}"; do
    [[ "$d" == "$buscar" ]] && echo "Encontrado" && exit
done
echo "No encontrado"
```

#### Variante B — Entrada estándar
```bash
read buscar
read -a datos
for d in "${datos[@]}"; do
    [[ "$d" == "$buscar" ]] && echo "Encontrado" && exit
done
echo "No encontrado"
```

#### Variante C — Argumentos
```bash
buscar="$1"
shift
for d in "$@"; do
    [[ "$d" == "$buscar" ]] && echo "Encontrado" && exit
done
echo "No encontrado"
```
