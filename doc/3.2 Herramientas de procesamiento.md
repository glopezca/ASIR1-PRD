# Anexo — Herramientas de procesamiento de texto en Bash: grep, sed y awk

Este anexo complementa la **Guía de expresiones regulares en Bash** y el **Manual de referencia de PHP y Bash**.  
Se centra en tres herramientas **fundamentales en ASIR** para trabajar con texto, ficheros y flujos estándar.

---

## 1. grep — Búsqueda de patrones

### 1.1 Qué es grep
`grep` (Global Regular Expression Print) es una herramienta para **buscar líneas que coinciden con un patrón**.

- Trabaja línea a línea.
- Usa expresiones regulares.
- Muy utilizada en logs y scripts.

---

### 1.2 Sintaxis básica
```bash
grep [opciones] PATRÓN fichero
```

Ejemplo:
```bash
grep "error" /var/log/syslog
```

---

### 1.3 Opciones más importantes

| Opción | Significado |
|------|-------------|
| `-i` | Ignorar mayúsculas/minúsculas |
| `-v` | Invertir coincidencia |
| `-n` | Mostrar número de línea |
| `-r` | Búsqueda recursiva |
| `-E` | Regex extendidas |
| `-o` | Mostrar solo la parte coincidente |

Ejemplo:
```bash
grep -in "fail" auth.log
```

---

### 1.4 grep con regex

```bash
grep -E '^[0-9]{3}' fichero.txt
```

Buscar IPs:
```bash
grep -E '([0-9]{1,3}\.){3}[0-9]{1,3}' fichero.txt
```

---

### 1.5 Uso en pipelines
```bash
ps aux | grep root
```

⚠️ Nota: puede aparecer el propio `grep`.  
Solución habitual:
```bash
ps aux | grep '[r]oot'
```

---

## 2. sed — Editor de flujo

### 2.1 Qué es sed
`sed` (Stream EDitor) permite **transformar texto** mientras fluye por un pipeline.

- No edita ficheros por defecto.
- Muy eficiente.
- Orientado a sustituciones.

---

### 2.2 Sintaxis básica
```bash
sed 'orden' fichero
```

Ejemplo:
```bash
sed 's/error/ERROR/' log.txt
```

---

### 2.3 Sustitución (comando s)

```bash
sed 's/patrón/reemplazo/'
```

Opciones:
- `g` → global
- `i` → ignorar mayúsculas

```bash
sed 's/error/ERROR/g' log.txt
```

---

### 2.4 Uso con regex

```bash
sed -E 's/^([0-9]{4})-([0-9]{2})-([0-9]{2})/Fecha: \3-\2-\1/' fechas.txt
```

---

### 2.5 Edición en fichero (con cuidado)

```bash
sed -i 's/localhost/127.0.0.1/g' config.conf
```

⚠️ En producción, hacer backup:
```bash
sed -i.bak 's/localhost/127.0.0.1/g' config.conf
```

---

## 3. awk — Procesamiento estructurado

### 3.1 Qué es awk
`awk` es un **lenguaje de procesamiento de texto orientado a campos**.

- Ideal para ficheros estructurados.
- Trabaja con columnas.
- Tiene variables, condiciones y bucles.

---

### 3.2 Sintaxis básica
```bash
awk 'patrón { acción }' fichero
```

Ejemplo:
```bash
awk '{ print $1 }' fichero.txt
```

---

### 3.3 Separador de campos

Por defecto: espacios/tabuladores.

```bash
awk -F: '{ print $1 }' /etc/passwd
```

---

### 3.4 Variables internas útiles

| Variable | Significado |
|--------|-------------|
| `NF` | Número de campos |
| `NR` | Número de línea |
| `$0` | Línea completa |
| `$1..$n` | Campos |

Ejemplo:
```bash
awk '{ print NR, NF, $0 }' fichero.txt
```

---

### 3.5 Condiciones

```bash
awk '$3 > 100 { print $1, $3 }' datos.txt
```

---

### 3.6 BEGIN y END

```bash
awk 'BEGIN { print "Inicio" } { print $1 } END { print "Fin" }' fichero.txt
```

---

### 3.7 awk con regex

```bash
awk '/error/ { print NR ":" $0 }' log.txt
```

---

## 4. Comparación rápida

| Herramienta | Uso principal |
|------------|---------------|
| `grep` | Buscar líneas |
| `sed` | Transformar texto |
| `awk` | Procesar columnas y lógica |

---

## 5. Ejemplo combinado (real ASIR)

```bash
cat access.log | grep -E '^[0-9]' | sed 's/HTTP\/1.1//g' | awk '{ print $1, $7 }'
```

---

## 6. Resumen clave

- `grep` → filtra
- `sed` → transforma
- `awk` → interpreta

Dominar estas tres herramientas es **esencial para scripting profesional en Bash**.
