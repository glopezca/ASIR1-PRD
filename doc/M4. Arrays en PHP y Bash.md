# 📦 Arrays en PHP y Bash

Manual exhaustivo y didáctico sobre el manejo de **arrays en PHP y Bash**, con ejemplos prácticos,
comparativa conceptual, **funciones de ordenación**, **operaciones de resultado (suma, media, etc.)**
y errores frecuentes. Orientado a **ASIR / SMR / scripting profesional**.

---

## 🐘 1. Arrays en PHP

En PHP, los arrays son **estructuras de datos de primer nivel**, muy potentes y flexibles:

- Arrays indexados, asociativos y mixtos
- Dinámicos
- Amplísimo conjunto de funciones estándar
- Uso intensivo en backend y lógica de negocio

---

### 1.1 Declaración de arrays en PHP

```php
$numeros = [3, 7, 2, 9];
$edades = ["Ana" => 30, "Luis" => 25];
```

---

### 1.2 Recorrido de arrays en PHP

```php
foreach ($numeros as $n) {
    echo $n . PHP_EOL;
}

foreach ($edades as $nombre => $edad) {
    echo "$nombre → $edad" . PHP_EOL;
}
```

---

### 1.3 Funciones de información y resultado

```php
count($numeros);
array_sum($numeros);
max($numeros);
min($numeros);
array_product($numeros);
```

Media:
```php
$media = array_sum($numeros) / count($numeros);
```

---

### 1.4 Funciones de ordenación en PHP

| Función | Descripción |
|------|-------------|
| sort | Ordena valores y reindexa |
| rsort | Orden descendente |
| asort | Ordena valores manteniendo claves |
| ksort | Ordena por claves |
| arsort | Valores descendente con claves |
| krsort | Claves descendente |
| usort | Orden personalizada |
| uasort | Orden personalizada con claves |
| uksort | Orden personalizada por claves |

Ejemplo:
```php
sort($numeros);
```

---

### 1.5 Transformación y filtrado

```php
$pares = array_filter($numeros, fn($n) => $n % 2 === 0);
$dobles = array_map(fn($n) => $n * 2, $numeros);
$total = array_reduce($numeros, fn($acc, $n) => $acc + $n, 0);
```

---

### 1.6 Errores frecuentes en PHP

- Usar sort sin entender el efecto sobre las claves
- No validar arrays vacíos
- Reimplementar funciones existentes

## 🐚 2. Arrays en Bash

```bash
numeros=(3 7 2 9)
```

---

### 2.1 Recorrido

```bash
for n in "${numeros[@]}"; do
    echo "$n"
done
```

---

### 2.2 `${array[@]}` vs `${!array[@]}`

```bash
for i in "${!numeros[@]}"; do
    echo "Índice $i → ${numeros[$i]}"
done
```

---

### 2.3 Resultados numéricos en Bash

Suma:
```bash
suma=0
for n in "${numeros[@]}"; do
    (( suma += n ))
done
```

Media:
```bash
media=$(( suma / ${#numeros[@]} ))
```

---

### 2.4 Ordenación en Bash

```bash
ordenados=($(printf "%s
" "${numeros[@]}" | sort -n))
```

---

### 2.5 Errores frecuentes en Bash

- Creer que existen funciones de array como en PHP
- Olvidar comillas
- Usar herramientas externas innecesarias

---

| Suma/media | Funciones | Bucles |
