# 📦 Arrays en PHP y Bash — Manual ampliado y comparativo

Manual **exhaustivo, didáctico y orientado a ASIR/SMR** sobre el manejo de arrays en **PHP** y **Bash**.
Incluye **explicación detallada de cada función relevante de PHP**, **sintaxis completa en Bash**,
ejemplos correctos, errores frecuentes y una **comparativa profunda** entre ambos lenguajes.

---

## 🐘 1. Arrays en PHP (explicación completa)

En PHP, el array es una **estructura central del lenguaje**:
- Es un **mapa ordenado** (clave → valor).
- Las claves pueden ser **enteros o strings**.
- Puede ser **indexado, asociativo o mixto**.
- Se usa tanto para **listas** como para **diccionarios**.

---

### 1.1 Declaración de arrays en PHP

```php
$nums = [3, 7, 2, 9];
$edades = ["Ana" => 30, "Luis" => 25];
```

PHP permite arrays mixtos:
```php
$mixto = [0 => "rojo", "edad" => 30];
```

---

### 1.2 Recorrido de arrays en PHP

#### foreach (forma correcta y segura)
```php
foreach ($nums as $n) {
    echo $n . PHP_EOL;
}
```

#### Clave y valor
```php
foreach ($edades as $nombre => $edad) {
    echo "$nombre → $edad" . PHP_EOL;
}
```

👉 `foreach` **no depende de índices consecutivos** y evita errores comunes de `for`.

---

## 1.3 Funciones de información y resultado en PHP

### `count()`
Número de elementos:
```php
count($nums);
```

### `array_sum()`
Suma total:
```php
array_sum($nums);
```

### `max()` / `min()`
```php
max($nums);
min($nums);
```

### `array_product()`
Producto de todos los valores:
```php
array_product($nums);
```

### Media (no existe función directa)
```php
$media = array_sum($nums) / count($nums);
```

⚠️ Error frecuente: no comprobar array vacío.

---

## 1.4 Funciones de inserción y eliminación

### `array_push()` / `array_pop()`
```php
array_push($nums, 10);
array_pop($nums);
```

### `array_shift()` / `array_unshift()`
```php
array_shift($nums);
array_unshift($nums, 1);
```

### `unset()`
```php
unset($nums[2]);
```

⚠️ `unset()` **no reindexa automáticamente**.

---

## 1.5 Funciones de búsqueda y comprobación

### `in_array()`
```php
in_array(7, $nums);
```

### `array_key_exists()`
```php
array_key_exists("Ana", $edades);
```

---

## 1.6 Transformación y reducción

### `array_map()`
```php
$dobles = array_map(fn($n) => $n * 2, $nums);
```

### `array_filter()`
```php
$pares = array_filter($nums, fn($n) => $n % 2 === 0);
```

### `array_reduce()`
```php
$total = array_reduce($nums, fn($acc, $n) => $acc + $n, 0);
```

---

## 1.7 Ordenación en PHP (CRÍTICO)

| Función | Qué ordena | Mantiene claves |
|------|------------|----------------|
| `sort()` | valores ↑ | ❌ |
| `rsort()` | valores ↓ | ❌ |
| `asort()` | valores ↑ | ✔ |
| `arsort()` | valores ↓ | ✔ |
| `ksort()` | claves ↑ | ✔ |
| `krsort()` | claves ↓ | ✔ |
| `usort()` | personalizada | ❌ |
| `uasort()` | personalizada | ✔ |
| `uksort()` | claves personalizadas | ✔ |

Ejemplo:
```php
asort($edades);
```

---

## 1.8 Errores frecuentes en PHP

- Confundir `sort()` con `asort()`
- Reimplementar funciones estándar
- Asumir índices consecutivos
- No validar arrays vacíos

## 🐚 2. Arrays en Bash (explicación completa)

En Bash, los arrays son **variables del shell**, no estructuras complejas:
- Solo disponibles en Bash (no POSIX `sh`)
- No tipados
- No anidados reales
- Adecuados para **listas simples**

---

### 2.1 Declaración

```bash
nums=(3 7 2 9)
```

Arrays asociativos (Bash ≥ 4):
```bash
declare -A edades
edades[Ana]=30
edades[Luis]=25
```

---

### 2.2 Acceso

```bash
echo "${nums[0]}"
echo "${edades[Ana]}"
```

---

### 2.3 Expansión de arrays

#### Valores
```bash
"${nums[@]}"
```

#### Índices / claves
```bash
"${!nums[@]}"
```

Ejemplo completo:
```bash
for i in "${!nums[@]}"; do
    echo "$i → ${nums[$i]}"
done
```

---

### 2.4 Longitud

```bash
echo "${#nums[@]}"
```

---

### 2.5 Resultados numéricos en Bash

#### Suma
```bash
suma=0
for n in "${nums[@]}"; do
    (( suma += n ))
done
```

#### Media
```bash
media=$(( suma / ${#nums[@]} ))
```

---

### 2.6 Ordenación en Bash (no nativa)

```bash
ordenados=($(printf "%s
" "${nums[@]}" | sort -n))
```

⚠ Usa procesos externos.

---

### 2.7 Errores frecuentes en Bash

- Creer que existen funciones tipo PHP
- Olvidar comillas
- Usar arrays en `/bin/sh`
- Confundir globbing con regex

---

## ⚖️ 3. Comparativa detallada PHP vs Bash

| Aspecto | PHP | Bash |
|------|-----|------|
| Naturaleza | Lenguaje de programación | Intérprete de comandos |
| Arrays | Estructura central | Variable auxiliar |
| Asociativos | Sí | Sí (≥ Bash 4) |
| Funciones nativas | Muy numerosas | Prácticamente ninguna |
| Ordenación | Interna | Externa (`sort`) |
| Rendimiento | Alto | Menor con procesos |
| Uso típico | Datos y lógica | Control y automatización |

---

## 🧠 Conclusión final

- PHP es **muy superior** en manipulación de arrays
- Bash es **suficiente** para scripting simple
