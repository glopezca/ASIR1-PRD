# Estándar mínimo evaluable de documentación de código

Documento orientado a **evaluación objetiva** en entornos profesionales y formativos (FP ASIR / SMR).

---

## 1. Principios no negociables

1. **La documentación vive en el código**.
2. **Debe poder generarse automáticamente**.
3. **Debe servir para entender, usar y mantener el código sin el autor presente**.
4. **Debe ser verificable y evaluable** (checklist clara).

Si no cumple los cuatro puntos, **no es documentación técnica válida**.

---

## 3. Plantilla base PHP (obligatoria)

```php
<?php

declare(strict_types=1);

/**
 * Nombre del fichero: calculadora.php
 * Autor: _______________________
 * Descripción: Funciones matemáticas básicas
 */

/**
 * Calcula el IVA de un importe.
 *
 * @param float $importe Importe base sin impuestos
 * @param float $tipo Tipo de IVA (por defecto 21%)
 * @return float Importe final con IVA
 */
function calcularIVA(float $importe, float $tipo = 0.21): float
{
    return $importe * (1 + $tipo);
}
```

---

## 4. Ejemplo evaluable correcto (PHP)

```php
/**
 * Convierte una cadena a mayúsculas de forma segura.
 *
 * @param string $texto Cadena de entrada
 * @return string Cadena en mayúsculas
 */
function convertirMayusculas(string $texto): string
{
    return mb_strtoupper($texto);
}
```

### Comentario docente
✔ Tipado correcto
✔ PHPDoc completo
✔ Función autoexplicativa
✔ Mantenible

---

## 8. Plantilla base Bash (obligatoria)

```bash
#!/bin/bash

# nombre: backup.sh
# descripcion: Realiza una copia de seguridad incremental
# uso: backup.sh ORIGEN DESTINO
# autor: _______________________

set -e

if [[ "$1" == "-h" || "$1" == "--help" ]]; then
    echo "Uso: backup.sh ORIGEN DESTINO"
    echo "Realiza copia de seguridad incremental con rsync"
    exit 0
fi

if [[ $# -ne 2 ]]; then
    echo "Error: número incorrecto de argumentos" >&2
    exit 1
fi

ORIGEN="$1"
DESTINO="$2"

rsync -av --delete "$ORIGEN" "$DESTINO"
```

---

## 9. Ejemplo evaluable correcto (Bash)

```bash
#!/bin/bash

# nombre: contar_lineas.sh
# descripcion: Cuenta el número de líneas de un fichero
# uso: contar_lineas.sh FICHERO

if [[ "$1" == "-h" ]]; then
    echo "Uso: contar_lineas.sh FICHERO"
    exit 0
fi

if [[ ! -f "$1" ]]; then
    echo "Error: el fichero no existe" >&2
    exit 1
fi

wc -l "$1"
```
