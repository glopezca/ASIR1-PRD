# Globbing y expresiones regulares en Bash

**Nivel:** ASIR / SMR  
**Objetivo:** comprender, diferenciar y usar correctamente *globbing* y **expresiones regulares** en Bash y en herramientas de la shell.

---

## Introducción: globbing vs expresiones regulares

### Globbing
- Lo interpreta **el propio shell** antes de ejecutar el comando.
- Se usa para expansión de nombres de fichero.
- No es un lenguaje de expresiones regulares.

Ejemplos:
```bash
ls *.txt
rm backup-202?.log
```

### Expresiones regulares (regex)
- Las interpreta un **motor regex** (no el shell).
- Se usan en contextos concretos (`[[ =~ ]]`, `grep`, `sed`, `awk`).
- Mucho más potentes y precisas.

Ejemplo:
```bash
[[ $dni =~ ^[0-9]{8}[A-Z]$ ]]
```

---

## 1. Dónde se usan expresiones regulares en Bash

### ✔️ Contextos válidos
- `[[ cadena =~ regex ]]`
- `grep`, `egrep` (`egrep` es equivalente a `grep -E`)
- `sed`
- `awk`
- `vi` / `vim`
- `expr`
- `csplit`
- `diff` parcialmente, en opciones concretas con `-I` como en:
```bash
diff -I '^#' fich1 fich2
````

### ❌ Contextos NO válidos
- `[ ]` (test POSIX)
- `case` (usa globbing)
- Comparaciones `==` con patrones simples

---

## 2. Sintaxis básica en `[[ =~ ]]`

```bash
[[ $cadena =~ REGEX ]]
```

Ejemplo:
```bash
dni="12345678Z"
if [[ $dni =~ ^[0-9]{8}[A-Z]$ ]]; then
    echo "DNI válido"
fi
```

---

## 3. Metacaracteres fundamentales

| Símbolo | Significado | Ejemplo |
|-------|-------------|---------|
| `.` | Cualquier carácter | `a.c` |
| `^` | Inicio de cadena | `^Hola` |
| `$` | Fin de cadena | `fin$` |
| `*` | 0 o más | `ab*` |
| `+` | 1 o más | `ab+` |
| `?` | 0 o 1 | `colo?r` |

---

## 4. Clases de caracteres

### 4.1 Clases explícitas

| Clase | Significado |
|-----|-------------|
| `[abc]` | a, b o c |
| `[a-z]` | letras minúsculas |
| `[A-Z]` | letras mayúsculas |
| `[0-9]` | dígitos |
| `[^0-9]` | no dígitos |

Ejemplo:
```bash
[[ $var =~ ^[A-Z][a-z]+$ ]]
```

---

### 4.2 Clases POSIX (recomendadas)

| Clase | Significado |
|------|-------------|
| `[[:digit:]]` | dígitos |
| `[[:alpha:]]` | letras |
| `[[:alnum:]]` | letras o números |
| `[[:upper:]]` | mayúsculas |
| `[[:lower:]]` | minúsculas |
| `[[:space:]]` | espacios |
| `[[:punct:]]` | puntuación |

Ejemplo:
```bash
[[ $usuario =~ ^[[:alpha:]][[:alnum:]_]{2,15}$ ]]
```

---

## 5. Cuantificadores

| Cuantificador | Significado |
|-------------|-------------|
| `{n}` | exactamente n |
| `{n,}` | al menos n |
| `{n,m}` | entre n y m |

Ejemplo:
```bash
[[ $cp =~ ^[0-9]{5}$ ]]
```

---

## 6. Agrupaciones y alternancia

| Elemento | Uso |
|--------|-----|
| `( )` | agrupar |
| `\|` | OR lógico |

Ejemplo:
```bash
[[ $resp =~ ^(si|no|quizas)$ ]]
```

---

## 7. Variables y comillas (MUY IMPORTANTE)

### ✔️ Correcto
```bash
[[ $cadena =~ ^[a-z]+$ ]]
```

### ❌ Incorrecto
```bash
[[ "$cadena" =~ "^[a-z]+$" ]]
```

> Las comillas **rompen el regex** en `[[ =~ ]]`.

---

## 8. Capturas (BASH_REMATCH)

```bash
fecha="2024-12-31"

if [[ $fecha =~ ^([0-9]{4})-([0-9]{2})-([0-9]{2})$ ]]; then
    echo "Año: ${BASH_REMATCH[1]}"
    echo "Mes: ${BASH_REMATCH[2]}"
    echo "Día: ${BASH_REMATCH[3]}"
fi
```

---

## 9. Uso de regex en herramientas externas

### grep
```bash
grep '^[A-Z]' fichero.txt
```

### sed
```bash
sed -E 's/([0-9]{4})-([0-9]{2})-([0-9]{2})/\3\/\2\/\1/' fechas.txt
```

### awk
```bash
awk '/^[A-Z]/{print $1}' datos.txt
```

---

## 10. Regex y sort (uso combinado)

> `sort` **NO interpreta regex**, pero se usa tras filtros regex.

```bash
grep 'ERROR' log.txt | sort | uniq -c
```

---

## 11. Regex vs globbing (tabla comparativa)

| Característica | Regex (`=~`) | Globbing |
|--------------|-------------|----------|
| Motor | Regex real | Shell |
| Potencia | Alta | Media |
| `{n}` | Sí | No |
| Alternancia `|` | Sí | No |
| Uso en `case` | No | Sí |

---

## 12. Errores típicos de alumnado

- Usar regex en `[ ]`
- Poner regex entre comillas
- Confundir globbing con regex
- No usar `^` y `$`

---

## 13. Resumen rápido (chuleta)

- Globbing → expansión de ficheros
- Regex → validación y análisis
- Regex en Bash → `[[ =~ ]]`
- Sin comillas en el patrón
- Preferir clases POSIX
- Capturas → `${BASH_REMATCH[n]}`

# Anexo — POSIX BRE vs POSIX ERE vs PCRE

Este documento es un **anexo completo y autónomo**, diseñado para **copiar, pegar o adjuntar** al final del manual **"Globbing y expresiones regulares en Bash"**.
Orientado a **ASIR / SMR** y administración de sistemas UNIX/Linux.

---

## 1️⃣ Visión general

| Tipo | Nombre completo | Estándar | Complejidad | Uso típico |
|----|----------------|----------|-------------|-----------|
| **BRE** | Basic Regular Expressions | POSIX | Baja | `sed`, `grep` |
| **ERE** | Extended Regular Expressions | POSIX | Media | `grep -E`, `awk` |
| **PCRE** | Perl Compatible Regular Expressions | No POSIX | Alta | `grep -P`, lenguajes modernos |

---

## 2️⃣ POSIX BRE (Basic Regular Expressions)

### Características generales
- Regex histórico y limitado.
- Metacaracteres escapados.
- Máxima portabilidad.

### Herramientas
- `grep`
- `sed`
- `ed`
- `expr`

### Sintaxis clave

| Elemento | Sintaxis | Nota |
|--------|---------|------|
| Repetición | `\{n,m\}` | Escape obligatorio |
| Grupo | `\( … \)` | Escape obligatorio |
| Alternancia | ❌ | No disponible |

### Ejemplo

```bash
grep '^[A-Z]\{3\}[0-9]\{2\}$' archivo
```

---

## 3️⃣ POSIX ERE (Extended Regular Expressions)

### Características
- Más legible.
- POSIX estándar.

### Herramientas
- `grep -E`
- `awk`
- `sed -E`

### Ejemplo

```bash
grep -E '^(root|daemon):' /etc/passwd
```

---

## 4️⃣ PCRE

### Características
- No POSIX.
- Muy potente.

### Ejemplo

```bash
grep -P '(?<=user=)[a-z0-9_]+' log.txt
```

---

## 5️⃣ Comparativa

| Característica | BRE | ERE | PCRE |
|--------------|-----|-----|------|
| POSIX | ✔️ | ✔️ | ❌ |
| Portabilidad | Alta | Alta | Baja |

---

## 6️⃣ Resumen

- `grep` → BRE
- `grep -E` → ERE
- `grep -P` → PCRE
