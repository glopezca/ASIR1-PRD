# Manual comparativo de versiones de un programa PHP y documentación con phpDocumentor

**Nivel:** CFGS ASIR / Backend PHP  
**Formato:** Markdown (.md)  
**Objetivo:** analizar distintas formas de resolver un mismo problema en PHP, evaluar sus fortalezas y debilidades y aprender a generar documentación profesional con phpDocumentor.

---

## 1. Problema de referencia

El problema abordado en todas las versiones es el mismo:

> Analizar un fichero de log HTTP desde línea de comandos y obtener estadísticas:
> - número total de accesos  
> - accesos por código HTTP  
> - accesos por IP  

Todas las versiones:
- se ejecutan desde CLI (`php script.php fichero.log`)
- usan entrada por argumentos
- producen salida por STDOUT

---

## 2. Versión 1 — Script plano, sin funciones ni tipado

### Características
- Código secuencial
- Uso directo de `$argv` y `$argc`
- Sin funciones
- Sin tipado estricto
- Sin documentación estructurada

### Fortalezas
- ✔ Muy fácil de entender
- ✔ Adecuada para primeros contactos con PHP
- ✔ Rápida de escribir

### Debilidades
- ❌ Código largo y monolítico
- ❌ Difícil de reutilizar
- ❌ No escalable
- ❌ Imposible generar documentación automática

### Uso recomendado
- Introducción a PHP CLI
- Scripts muy pequeños
- Aprendizaje inicial

---

## 3. Versión 2 — Con funciones, sin tipado ni phpdoc

### Características
- Código modularizado en funciones
- Separación clara de responsabilidades
- Sin tipado estricto
- Sin DocBlocks

### Fortalezas
- ✔ Código más limpio y mantenible
- ✔ Facilita la reutilización
- ✔ Permite pruebas parciales

### Debilidades
- ❌ Falta de contratos de tipos
- ❌ No genera documentación automática
- ❌ Mayor riesgo de errores silenciosos

### Uso recomendado
- Nivel intermedio
- Aprender diseño estructurado
- Buen paso previo a programación profesional

---

## 4. Versión 3 — Sin funciones, con DocBlocks

### Características
- Código secuencial
- Uso de DocBlocks (`/** */`)
- Documentación de variables y bloques
- Sin funciones
- Sin tipado estricto

### Fortalezas
- ✔ Introduce la cultura de documentación
- ✔ Permite usar phpDocumentor parcialmente
- ✔ Mejora la comprensión del código

### Debilidades
- ❌ Mala estructura interna
- ❌ DocBlocks sin funciones tienen utilidad limitada
- ❌ No es diseño profesional

### Uso recomendado
- Aprender sintaxis phpdoc
- Entender la diferencia entre comentar y documentar
- Transición hacia código profesional

---

## 5. Versión 4 — Profesional: funciones, tipado estricto y phpdoc

### Características
- Uso de `declare(strict_types=1)`
- Funciones bien definidas
- Tipos en parámetros y retornos
- DocBlocks completos
- Preparado para phpDocumentor

### Fortalezas
- ✔ Código robusto y mantenible
- ✔ Autodocumentable
- ✔ Escalable
- ✔ Nivel profesional real
- ✔ Alineado con frameworks modernos

### Debilidades
- ❌ Curva de aprendizaje mayor
- ❌ Requiere disciplina y conocimiento previo

### Uso recomendado
- Proyectos reales
- Evaluaciones finales
- Entorno profesional
- Base para Laravel / Symfony

## 7. Documentación con phpDocumentor

### 7.1 Qué es phpDocumentor

phpDocumentor es la herramienta estándar para:
- generar documentación automática
- a partir de DocBlocks
- en HTML navegable

Solo interpreta comentarios con este formato:

```php
/**
 * Comentario válido para phpDocumentor
 */
```

---

## 7.2 Requisitos

- PHP ≥ 8.0
- Extensiones:
  - php-xml
  - php-mbstring

Instalación en Ubuntu / WSL:
```bash
sudo apt install php php-cli php-xml php-mbstring
```

---

## 7.3 Instalación de phpDocumentor

```bash
wget https://phpdoc.org/phpDocumentor.phar
chmod +x phpDocumentor.phar
sudo mv phpDocumentor.phar /usr/local/bin/phpdoc
```

Verificación:
```bash
phpdoc --version
```

## 7.4 Estructura típica de proyecto

```text
proyecto/
├── src/
│   └── LogAnalyzer.php
├── docs/
```

---

## 7.5 Generación de la documentación

Desde la raíz del proyecto:

```bash
phpdoc -d src -t docs
```

Resultado:
- `docs/index.html`
- navegación por clases, funciones y métodos

## 8. Errores comunes (evaluables)

- Usar `//` en lugar de `/** */`
- No documentar parámetros
- Documentar código sin funciones
- No tipar argumentos

---

## 9. Conclusión pedagógica

Este recorrido muestra claramente que:

> **No todo código que funciona es buen código.**

La progresión correcta es:
1. entender el problema
2. estructurar el código
3. documentarlo
4. tiparlo
5. automatizar su documentación

La **versión 4** representa el estándar profesional esperado en ASIR.

### 10.1 Versión 1 — Sin funciones ni tipado

```php
<?php

if ($argc < 2) {
    echo "Uso: php log.php fichero.log
";
    exit(1);
}

$fichero = $argv[1];

if (!file_exists($fichero)) {
    echo "El fichero no existe
";
    exit(1);
}

$lineas = file($fichero, FILE_IGNORE_NEW_LINES);
$total = 0;
$porCodigo = [];
$porIP = [];

foreach ($lineas as $linea) {
    if (trim($linea) === "") continue;

    $p = explode(" ", $linea);
    if (count($p) < 5) continue;

    $ip = $p[0];
    $codigo = $p[4];

    $total++;

    $porCodigo[$codigo] = ($porCodigo[$codigo] ?? 0) + 1;
    $porIP[$ip] = ($porIP[$ip] ?? 0) + 1;
}

echo "Total accesos: $total
";

echo "Por código HTTP:
";
foreach ($porCodigo as $c => $n) {
    echo "  $c => $n
";
}

echo "Por IP:
";
foreach ($porIP as $ip => $n) {
    echo "  $ip => $n
";
}
```

### 10.2 Versión 2 — Con funciones, sin tipado

```php
<?php

function leerLog($fichero) {
    return file($fichero, FILE_IGNORE_NEW_LINES);
}

function procesarLineas($lineas) {
    $res = ["total"=>0,"porCodigo"=>[],"porIP"=>[]];

    foreach ($lineas as $linea) {
        if (trim($linea) === "") continue;

        $p = explode(" ", $linea);
        if (count($p) < 5) continue;

        $ip = $p[0];
        $codigo = $p[4];

        $res["total"]++;
        $res["porCodigo"][$codigo] = ($res["porCodigo"][$codigo] ?? 0) + 1;
        $res["porIP"][$ip] = ($res["porIP"][$ip] ?? 0) + 1;
    }

    return $res;
}

function mostrar($d) {
    echo "Total accesos: {$d['total']}
";
    foreach ($d["porCodigo"] as $c => $n) echo "Código $c => $n
";
    foreach ($d["porIP"] as $ip => $n) echo "IP $ip => $n
";
}

$datos = procesarLineas(leerLog($argv[1]));
mostrar($datos);
```

### 10.4 Versión 4 — Profesional (funciones, tipado y phpdoc)

```php
<?php
declare(strict_types=1);

/**
 * Analizador de logs HTTP
 */

function leerLog(string $ruta): array {
    return file($ruta, FILE_IGNORE_NEW_LINES) ?: [];
}

/**
 * @param array $lineas
 * @return array
 */
function procesarLog(array $lineas): array {
    $res = ["total"=>0,"porCodigo"=>[],"porIP"=>[]];

    foreach ($lineas as $linea) {
        if (trim($linea) === "") continue;

        $p = explode(" ", $linea);
        if (count($p) < 5) continue;

        [$ip,,,,$codigo] = $p;

        $res["total"]++;
        $res["porCodigo"][$codigo] = ($res["porCodigo"][$codigo] ?? 0) + 1;
        $res["porIP"][$ip] = ($res["porIP"][$ip] ?? 0) + 1;
    }

    return $res;
}

function mostrar(array $d): void {
    echo "Total accesos: {$d['total']}
";
    foreach ($d["porCodigo"] as $c => $n) echo "Código $c => $n
";
    foreach ($d["porIP"] as $ip => $n) echo "IP $ip => $n
";
}

$datos = procesarLog(leerLog($argv[1]));
mostrar($datos);
```
