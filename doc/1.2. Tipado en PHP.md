# Introducción al tipado en PHP

Guía técnica y docente para introducir **tipado moderno y estricto en PHP** de forma correcta, evaluable y alineada con buenas prácticas profesionales.

---

## 1. Principio fundamental

En PHP **no existe tipado real sin `strict_types`**. Todo lo demás es incompleto o engañoso.

```php
<?php
declare(strict_types=1);
```

### Qué implica
- PHP **no realiza conversiones implícitas**
- Los errores aparecen antes
- El contrato de las funciones se cumple o falla

> **Sin `strict_types=1`, el tipado es cosmético.**

---

## 2. Tipado de parámetros

### Ejemplo correcto
```php
function sumar(int $a, int $b): int {
    return $a + $b;
}
```

### Ejemplo incorrecto
```php
function sumar($a, $b) {
    return $a + $b;
}
```

❌ Ambiguo
❌ No documenta intención
❌ Propenso a errores

---

## 3. Tipado de retorno (obligatorio)

El tipo de retorno define el **contrato funcional**.

```php
function obtenerNombre(): string {
    return "Ana";
}
```

Si se devuelve otro tipo → **error inmediato**.

---

## 4. Tipos escalares básicos

| Tipo | Uso |
|----|----|
| `int` | Enteros |
| `float` | Decimales |
| `string` | Texto |
| `bool` | Booleanos |
| `array` | Colecciones |
| `object` | Objetos genéricos |

---

## 5. Tipos especiales

### 5.1 Nullable (`?tipo`)
```php
function buscarUsuario(int $id): ?string {
    return null;
}
```

✔ Puede devolver `string` o `null`

---

### 5.2 Tipos unión (PHP 8+)
```php
function normalizar(int|string $valor): string {
    return (string)$valor;
}
```

✔ Útiles
❌ Abuso indica mal diseño

---

### 5.3 `mixed`
```php
function procesar(mixed $dato): mixed {
    return $dato;
}
```

⚠ Último recurso
⚠ Solo para capas genéricas

---

## 6. Tipado en clases y propiedades

```php
class Usuario {
    public int $id;
    public string $nombre;
}
```

✔ Define estructura
✔ Evita estados inválidos

---

## 7. Tipado de arrays (limitación real)

PHP **no permite tipar el contenido de arrays** nativamente.

### Soluciones prácticas

#### 7.1 PHPDoc
```php
/**
 * @return int[]
 */
function obtenerIds(): array {
    return [1, 2, 3];
}
```

#### 7.2 Clases DTO (recomendado)
```php
class Producto {
    public int $id;
    public float $precio;
}
```

---

## 8. Tipado + PHPDoc (modelo correcto)

```php
/**
 * Calcula el IVA de un importe.
 *
 * @param float $importe Importe base
 * @param float $tipo Tipo de IVA
 * @return float Importe final
 */
function calcularIVA(float $importe, float $tipo = 0.21): float {
    return $importe * (1 + $tipo);
}
```

✔ El tipo **manda**
✔ El PHPDoc **explica**

---

## 9. Errores comunes (criterio de suspenso)

- No usar `declare(strict_types=1)`
- Tipar solo algunas funciones
- Abusar de `mixed`
- Confiar solo en PHPDoc
- Devolver `null` sin declararlo

---

## 10. Regla clara

> **PHP moderno sin tipado estricto NO es código profesional.**

Este nivel es el **mínimo exigible** en entornos reales y formativos.
