# Manual de instalación y uso de **phpDocumentor (phpdoc)**  
**Entornos:** Ubuntu (WSL) y GitHub Codespaces  
**Nivel:** ASIR / Desarrollo Backend  
**Objetivo:** instalar phpDocumentor, documentar código PHP correctamente y generar/visualizar documentación HTML.

---

## 1. ¿Qué es phpDocumentor?

**phpDocumentor** es la herramienta estándar del ecosistema PHP para:
- generar documentación automática
- a partir de **comentarios DocBlock**
- en formato **HTML navegable**

Es el equivalente en PHP a:
- `javadoc` (Java)
- `doxygen` (C/C++)

---

## 2. Requisitos previos

### 2.1 PHP
```bash
php -v
```

Recomendado:
- PHP ≥ 8.0

Si no está instalado (Ubuntu / WSL):
```bash
sudo apt update
sudo apt install -y php php-cli php-xml php-mbstring
```

---

## 3. Instalación de phpDocumentor en Ubuntu (WSL)

### 3.1 Descarga del binario oficial
```bash
wget https://phpdoc.org/phpDocumentor.phar
```

### 3.2 Hacerlo ejecutable
```bash
chmod +x phpDocumentor.phar
```

### 3.3 Moverlo a PATH (opcional, recomendado)
```bash
sudo mv phpDocumentor.phar /usr/local/bin/phpdoc
```

### 3.4 Verificar instalación
```bash
phpdoc --version
```

---

## 4. Instalación en GitHub Codespaces

### 4.1 Comprobar PHP
```bash
php -v
```

### 4.2 Instalar phpDocumentor
```bash
wget https://phpdoc.org/phpDocumentor.phar
chmod +x phpDocumentor.phar
sudo mv phpDocumentor.phar /usr/local/bin/phpdoc
```

### 4.3 Alternativa con Composer
```bash
composer global require phpdocumentor/phpdocumentor
```

## 5. Sintaxis correcta de comentarios en PHP (DocBlocks)

### 5.1 Regla fundamental
phpDocumentor **NO interpreta**:
```php
// comentario
/* comentario */
```

Solo interpreta **DocBlocks**:
```php
/**
 * Comentario válido
 */
```

---

### 5.2 DocBlock de función
```php
/**
 * Suma dos números
 *
 * @param int $a Primer número
 * @param int $b Segundo número
 * @return int Resultado
 */
function suma(int $a, int $b): int {
    return $a + $b;
}
```

---

### 5.3 DocBlock de clase
```php
/**
 * Clase Calculadora
 *
 * Operaciones matemáticas básicas
 */
class Calculadora {

    /**
     * Multiplica dos números
     *
     * @param int $a
     * @param int $b
     * @return int
     */
    public function multiplicar(int $a, int $b): int {
        return $a * $b;
    }
}
```

---

### 5.4 Etiquetas importantes

| Etiqueta | Uso |
|--------|----|
| `@param` | Parámetros |
| `@return` | Valor devuelto |
| `@var` | Tipo |
| `@throws` | Excepciones |
| `@deprecated` | Obsoleto |

## 6. Estructura típica de proyecto

proyecto/

│   └── Utils.php

## 7. Generación de documentación

```bash
phpdoc -d src -t docs
```

---

## 8. Visualización de la documentación

### 8.1 Apertura local SIN servidor web (recomendado para WSL)

La documentación generada por phpDocumentor es **HTML estático**, por lo que **NO es obligatorio usar un servidor web**.

Si la distribución Linux tiene un navegador instalado, se puede abrir directamente:

```bash
firefox docs/index.html
```

O con otros navegadores habituales:

```bash
chromium docs/index.html
google-chrome docs/index.html
brave-browser docs/index.html
```

Esto es especialmente útil cuando:
- se trabaja en **WSL con entorno gráfico**
- se quiere evitar levantar servidores innecesarios
- se revisa documentación de forma local y rápida

⚠️ En **Codespaces**, esta opción no suele estar disponible porque no hay navegador gráfico.


### WSL
```bash
xdg-open docs/index.html
```

o
```bash
php -S localhost:8000 -t docs
```

### Codespaces
```bash
php -S 0.0.0.0:8000 -t docs
```

## 9. Errores comunes
- No usar `/** */`
- No documentar parámetros
- No tipar funciones
