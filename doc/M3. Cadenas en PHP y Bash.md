# Manual de manipulación de cadenas en PHP y Bash

## 1. Manipulación de cadenas en PHP

### Concatenación
En PHP **NO** se usa `+` para concatenar.

```php
$nombre = "Ana";
$saludo = "Hola " . $nombre;
```

❌ Error frecuente:
```php
$saludo = "Hola " + $nombre; // INCORRECTO
```

---

### Comillas simples vs dobles
- **Dobles**: interpolan variables y caracteres especiales
- **Simples**: texto literal

```php
echo "Hola $nombre\n";
echo 'Hola $nombre\n';
```

---

### Funciones habituales
```php
strlen($s);
substr($s, 1, 3);
strpos($s, "a");
str_replace("a", "o", $s);
explode(",", $s);
implode("-", $arr);
trim($s);
strtolower($s);
strtoupper($s);
```

---

### Errores comunes en PHP
- Pensar que las constantes se interpolan
- Confundir concatenación con suma
- No usar funciones multibyte cuando procede (`mb_*`)

---

## 2. Manipulación de cadenas en Bash

### 2.1 Expansión de parámetros con `${}`

```bash
nombre="Ana"
echo ${nombre}
```

#### Minúsculas / Mayúsculas
```bash
texto="HoLa"
echo ${texto,,}
echo ${texto^^}
```

#### Subcadenas
```bash
echo ${texto:1:2}
```

#### Longitud
```bash
echo ${#texto}
```

#### Sustitución
```bash
ruta="/home/ana/docs"
echo ${ruta/docs/documentos}
```

---

### Errores frecuentes en Bash
- Usar `$var` en contextos ambiguos
- Usar herramientas externas innecesarias
- Confundir globbing con regex

---

### 2.2 Uso de herramientas externas

#### tr
```bash
echo "HoLa" | tr 'A-Z' 'a-z'
```

#### rev
```bash
echo "radar" | rev
```

#### sed
```bash
echo "hola mundo" | sed 's/mundo/Bash/'
```

---

### Cuándo NO usar herramientas externas
- Dentro de bucles grandes
- Cuando Bash ofrece expansión nativa
- En scripts de alto rendimiento

---

## Comparativa PHP vs Bash

| Aspecto | PHP | Bash |
|-------|-----|------|
| Concatenación | `.` | Implícita |
| Transformaciones | Funciones | Expansión `${}` |
| Rendimiento | Alto | Depende de procesos externos |
