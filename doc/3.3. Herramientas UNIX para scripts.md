## 1. `wc` — Word Count

### 1.1 Qué es `wc`
`wc` es una herramienta para **contar líneas, palabras y caracteres** de un fichero o entrada estándar.

---

### 1.2 Sintaxis básica
```bash
wc [opciones] fichero
```

Ejemplo:
```bash
wc texto.txt
```

Salida típica:
```text
  10  120  850 texto.txt
```

Significado:
- líneas
- palabras
- bytes

---

### 1.3 Opciones importantes

| Opción | Significado |
|------|-------------|
| `-l` | Contar líneas |
| `-w` | Contar palabras |
| `-c` | Contar bytes |
| `-m` | Contar caracteres |
| `-L` | Longitud de la línea más larga |

Ejemplos:
```bash
wc -l texto.txt
wc -w texto.txt
wc -m texto.txt
```

---

### 1.4 Uso en scripts

```bash
lineas=$(wc -l < fichero.txt)
if (( lineas > 1000 )); then
    echo "Fichero grande"
fi
```

## 2. `cat` — Mostrar contenido

### Uso básico
```bash
cat fichero.txt
```

### Uso en scripts
```bash
cat fichero.txt | wc -l
```

⚠️ Evitar `cat` innecesario cuando se puede redirigir.

## 3. `less` y `more` — Visualización paginada

- `less` permite desplazarse arriba y abajo.
- No se usan normalmente dentro de scripts.
- Útiles para depuración manual.

```bash
less fichero.log
```

---

## 4. `head` y `tail` — Cabecera y final

### `head`
```bash
head fichero.txt
head -n 20 fichero.txt
```

### `tail`
```bash
tail fichero.txt
tail -n 50 fichero.txt
tail -f log.txt
```

Uso típico en scripts:
```bash
tail -n 1 fichero.txt
```

---

## 5. `cut` — Extracción de campos

### Sintaxis
```bash
cut -d: -f1 fichero
```

Opciones clave:
- `-d` → delimitador
- `-f` → campo

Ejemplo:
```bash
cut -d: -f1 /etc/passwd
```

---

## 6. `sort` — Ordenación

```bash
sort fichero.txt
sort -n numeros.txt
sort -r fichero.txt
sort -u fichero.txt
```

Opciones importantes:
- `-n` numérico
- `-r` inverso
- `-u` único

---

## 7. `uniq` — Eliminación de duplicados

⚠️ Requiere entrada ordenada.

```bash
sort fichero.txt | uniq
sort fichero.txt | uniq -c
```

---

## 8. `tr` — Traducción de caracteres

### Uso básico
```bash
tr 'a-z' 'A-Z' < fichero.txt
```

Eliminar caracteres:
```bash
tr -d ' ' < fichero.txt
```

---

## 9. `stat` — Información de ficheros

```bash
stat fichero.txt
```

Uso típico en scripts:
```bash
stat -c %s fichero.txt   # tamaño
stat -c %y fichero.txt   # fecha
```

## 13. Redirecciones y pipelines (recordatorio)

En la shell de Unix existen **tres flujos estándar**:

- `0` → entrada estándar (**STDIN**)
- `1` → salida estándar (**STDOUT**)
- `2` → salida de error (**STDERR**)

### Redirecciones habituales

```bash
comando > salida.txt        # STDOUT (sobrescribe)
comando >> salida.txt       # STDOUT (añade)
comando < entrada.txt       # STDIN
```

### Redirección de errores (STDERR)

```bash
comando 2> errores.txt      # STDERR (sobrescribe)
comando 2>> errores.txt     # STDERR (añade)
```

### Redirecciones combinadas

```bash
comando > salida.txt 2> errores.txt     # separa salida y errores
comando &> todo.txt                    # STDOUT + STDERR (Bash)
comando > todo.txt 2>&1                # forma portable
```

### Pipelines

```bash
comando1 | comando2 | comando3
```

Uso típico en scripts:
```bash
grep "error" fichero.log 2> errores.log | wc -l
```

## 14. Ejemplo completo real (ASIR)

```bash
#!/bin/bash

fichero="$1"

if [[ -f "$fichero" ]]; then
    echo "Líneas: $(wc -l < "$fichero")"
    echo "Palabras: $(wc -w < "$fichero")"
    echo "Tamaño: $(stat -c %s "$fichero") bytes"
    echo "Última línea:"
    tail -n 1 "$fichero"
else
    echo "No es un fichero válido"
fi
```

## 15. Resumen rápido

- `wc` → contar
- `head` / `tail` → cabecera / final
- `cut` / `sort` / `uniq` → procesar campos
- `tr` → transformar caracteres
- `stat` / `file` → metadatos
- `basename` / `dirname` → rutas

Dominar estas herramientas es **clave para scripting eficaz en Unix/Linux**.
