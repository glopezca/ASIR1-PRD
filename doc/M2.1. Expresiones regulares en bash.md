# Guía práctica de expresiones regulares en Bash

**Nivel:** ASIR / SMR  
**Objetivo:** comprender y usar expresiones regulares en Bash de forma correcta y realista.

> ⚠️ Importante: Bash **no usa expresiones regulares en todos los contextos**.  
> Solo están disponibles **principalmente en `[[ ]]` con el operador `=~`** y en herramientas externas (`grep`, `sed`, `awk`).

---

## 1. Dónde se usan expresiones regulares en Bash

### ✔️ Contextos válidos
- `[[ cadena =~ regex ]]`
- `grep`, `egrep`
- `sed`
- `awk`

### ❌ Contextos NO válidos
- `[ ]` (test POSIX)
- `case` (usa *globbing*, no regex)
- Comparaciones `==` con patrones simples

---

## 2. Sintaxis básica en `[[ =~ ]]`

```bash
[[ $cadena =~ REGEX ]]
```

Ejemplo:
```bash
dni="12345678Z"
if [[ $dni =~ ^[0-9]{8}[A-Z]$ ]]; then
    echo "DNI válido"
fi
```

---

## 3. Metacaracteres fundamentales

| Símbolo | Significado | Ejemplo |
|-------|-------------|---------|
| `.` | Cualquier carácter | `a.c` |
| `^` | Inicio de cadena | `^Hola` |
| `$` | Fin de cadena | `fin$` |
| `*` | 0 o más | `ab*` |
| `+` | 1 o más | `ab+` |
| `?` | 0 o 1 | `colou?r` |

---

## 4. Clases de caracteres

### Clases explícitas

| Clase | Significado |
|-----|-------------|
| `[abc]` | a, b o c |
| `[a-z]` | letras minúsculas |
| `[A-Z]` | letras mayúsculas |
| `[0-9]` | dígitos |
| `[^0-9]` | no dígitos |

Ejemplo:
```bash
[[ $var =~ ^[A-Z][a-z]+$ ]]
```

---

## 5. Clases POSIX (recomendadas)

| Clase | Significado |
|------|-------------|
| `[[:digit:]]` | dígitos |
| `[[:alpha:]]` | letras |
| `[[:alnum:]]` | letras o números |
| `[[:upper:]]` | mayúsculas |
| `[[:lower:]]` | minúsculas |
| `[[:space:]]` | espacios |
| `[[:punct:]]` | puntuación |

Ejemplo:
```bash
[[ $usuario =~ ^[[:alpha:]][[:alnum:]_]{2,15}$ ]]
```

---

## 6. Cuantificadores

| Cuantificador | Significado |
|-------------|-------------|
| `{n}` | exactamente n |
| `{n,}` | al menos n |
| `{n,m}` | entre n y m |

Ejemplo:
```bash
[[ $cp =~ ^[0-9]{5}$ ]]
```

---

## 7. Agrupaciones y alternancia

| Elemento | Uso |
|--------|-----|
| `( )` | agrupar |
| `|` | OR lógico |

Ejemplo:
```bash
[[ $resp =~ ^(si|no|quizas)$ ]]
```

---

## 8. Variables y comillas (MUY IMPORTANTE)

### ✔️ Correcto
```bash
[[ $cadena =~ ^[a-z]+$ ]]
```

### ❌ Incorrecto
```bash
[[ "$cadena" =~ "^[a-z]+$" ]]
```

> Las comillas **rompen el regex** en `[[ =~ ]]`.

---

## 9. Capturas (BASH_REMATCH)

```bash
fecha="2024-12-31"

if [[ $fecha =~ ^([0-9]{4})-([0-9]{2})-([0-9]{2})$ ]]; then
    echo "Año: ${BASH_REMATCH[1]}"
    echo "Mes: ${BASH_REMATCH[2]}"
    echo "Día: ${BASH_REMATCH[3]}"
fi
```

---

## 10. Ejemplos prácticos habituales (ASIR)

### Validar IP
```bash
[[ $ip =~ ^([0-9]{1,3}\.){3}[0-9]{1,3}$ ]]
```

### Validar usuario Linux
```bash
[[ $user =~ ^[a-z_][a-z0-9_-]{0,31}$ ]]
```

### Validar extensión de fichero
```bash
[[ $file =~ \.(txt|log|conf)$ ]]
```

---

## 11. Regex vs globbing (comparación clave)

| Característica | Regex (`=~`) | Globbing |
|--------------|-------------|----------|
| Potencia | Alta | Media |
| Regex reales | Sí | No |
| `*` | Repetición | Comodín |
| `{n}` | Sí | No |
| Uso en `case` | No | Sí |

---

## 12. Errores típicos de alumnos

- Usar regex en `[ ]`
- Poner regex entre comillas
- Confundir globbing con regex
- No usar `^` y `$`

---

## 13. Resumen rápido (chuleta)

- Regex en Bash → `[[ =~ ]]`
- No usar comillas en el regex
- Preferir clases POSIX
- Capturas → `${BASH_REMATCH[n]}`
