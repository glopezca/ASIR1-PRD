# ✅ SOLUCIONES EN BASH

## 🔹 BLOQUE A — Soluciones sin expresiones regulares

### Ejercicio 1
```bash
#!/bin/bash
wc "$1"
```

### Ejercicio 2
```bash
#!/bin/bash
i=1
for f in "$1"/*; do
    [[ -f "$f" ]] && echo "$i) $(basename "$f")" && ((i++))
done
```

### Ejercicio 3
```bash
#!/bin/bash
for ((i=$1+1;i<$2;i++)); do
    echo "$i"
done
```

### Ejercicio 4
```bash
#!/bin/bash
while read linea; do
    [[ -n "$linea" ]] && echo "$linea"
done < "$1"
```

### Ejercicio 5
```bash
#!/bin/bash
for arg in "$@"; do
    echo "$arg -> ${#arg}"
done
```

### Ejercicio 6
```bash
#!/bin/bash
nombres=()
while read n && [[ -n "$n" ]]; do
    nombres+=("$n")
done
echo "Total: ${#nombres[@]}"
```

### Ejercicio 7
```bash
#!/bin/bash
echo "Total argumentos: $#"
for a in "$@"; do echo "$a"; done
```

### Ejercicio 8
```bash
#!/bin/bash
total=0
for f in "$1"/*; do
    [[ -f "$f" ]] && (( total += $(stat -c %s "$f") ))
done
echo "$total"
```

### Ejercicio 9
```bash
#!/bin/bash
ls -lt "$1" | head -n 6
```

### Ejercicio 10
```bash
#!/bin/bash
for i in {1..10}; do
    echo "$1 x $i = $(( $1 * i ))"
done
```

### Ejercicio 11
```bash
#!/bin/bash
suma=0
while read n; do
    (( suma += n ))
done
echo "$suma"
```

### Ejercicio 12
```bash
#!/bin/bash
[[ $# -eq 0 ]] && { echo "Faltan argumentos"; exit 1; }
```

### Ejercicio 13
```bash
#!/bin/bash
for f in "$@"; do basename "$f"; done
```

### Ejercicio 14
```bash
#!/bin/bash
c=0
for f in "$1"/*; do [[ -e "$f" ]] && ((c++)); done
echo "$c"
```

### Ejercicio 15
```bash
#!/bin/bash
dest="$1"
shift
for f in "$@"; do cp "$f" "$dest"; done
```

## 🔹 BLOQUE B — Soluciones con expresiones regulares

### Ejercicio 16
```bash
#!/bin/bash
[[ $1 =~ ^([0-9]{1,3}\.){3}[0-9]{1,3}$ ]] && echo "IP válida"
```

### Ejercicio 17
```bash
#!/bin/bash
grep '[0-9]' "$1"
```

### Ejercicio 18
```bash
#!/bin/bash
for u in "$@"; do
    [[ $u =~ ^[a-z0-9]+$ ]] && echo "$u válido"
done
```

### Ejercicio 19
```bash
#!/bin/bash
grep -E '[0-9]{4}-[0-9]{2}-[0-9]{2}' "$1" | wc -l
```

### Ejercicio 20
```bash
#!/bin/bash
sed 's/[0-9]/X/g' "$1"
```

---

📌 **Nota:** Todas las soluciones son correctas pero no únicas. Se valorará el uso correcto de:
- bucles
- `$@`, `$#`, `shift`
- `[[ ]]`, `(( ))`
- redirecciones y pipelines
