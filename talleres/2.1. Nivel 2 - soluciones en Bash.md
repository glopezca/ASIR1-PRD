## 1. Imprimir una X de tamaño 10×10
```bash
size=10
for ((i=0;i<size;i++)); do
  for ((j=0;j<size;j++)); do
    if (( i==j || i+j==size-1 )); then echo -n "x"; else echo -n "."; fi
  done
  echo
done
```

## 5. Contar cuántos números son primos
```bash
read -a nums
count=0
is_prime() {
  local n=$1
  (( n<2 )) && return 1
  for ((i=2;i*i<=n;i++)); do (( n%i==0 )) && return 1; done
  return 0
}
for n in "${nums[@]}"; do
  if is_prime "$n"; then count=$((count+1)); fi
done
echo "$count"
```

## 7. Rotación circular de lista
```bash
read -a nums
read m
len=${#nums[@]}
for ((k=0;k<m;k++)); do
  last=${nums[len-1]}
  for ((i=len-1;i>0;i--)); do nums[i]=${nums[i-1]}; done
  nums[0]=$last
done
echo "${nums[@]}"
```

## 9. Detectar palíndromos en un conjunto de palabras

### 🟢 Solución 1 – Uso de `tr` y `rev` (enfoque clásico Unix)

Esta versión utiliza **herramientas externas** estándar: `tr` para normalizar mayúsculas/minúsculas y `rev` para invertir la cadena.

```bash
while true; do
  # Bucle infinito; se interrumpe manualmente con break

  read w
  # Lee una palabra desde la entrada estándar y la guarda en la variable w

  [[ $w == "fin" ]] && break
  # Si el usuario introduce "fin", se sale del bucle

  lower=$(echo "$w" | tr 'A-Z' 'a-z')
  # Convierte la palabra a minúsculas:
  # - echo envía la palabra a stdout
  # - tr sustituye letras A-Z por a-z
  # - $(...) captura el resultado

  rev=$(echo "$lower" | rev)
  # rev invierte el orden de los caracteres de la cadena

  [[ $lower == $rev ]] && echo "$w -> Sí" || echo "$w -> No"
  # Compara la cadena normalizada con su versión invertida
done
```

#### Comentarios técnicos
- `tr` y `rev` son **procesos externos**
- Enfoque muy claro para introducir **pipes**
- No es Unicode-safe (acentos, ñ)

---

### 🟡 Solución 2 – Sin `tr`, usando solo Bash + `rev`

Esta versión evita `tr` y usa **expansión de parámetros de Bash** para convertir a minúsculas.

```bash
while true; do
  read w
  # Lectura desde entrada estándar

  [[ $w == "fin" ]] && break
  # Condición de salida

  lower=${w,,}
  # ${var,,} convierte todos los caracteres alfabéticos a minúsculas
  # Funcionalidad propia de Bash (>= versión 4)

  rev=$(rev <<< "$lower")
  # <<< es un here-string que pasa la variable directamente a rev

  if [[ $lower == $rev ]]; then
    echo "$w -> Sí"
  else
    echo "$w -> No"
  fi
done
```

#### Comentarios técnicos
- Menos procesos externos → mejor rendimiento
- Más dependiente de Bash (no POSIX)
- Muy adecuada para scripts Bash modernos

---

### 🔵 Solución 3 – Sin `tr` y sin `rev` (solo Bash puro)

Esta versión implementa manualmente la inversión de la cadena mediante un **bucle y expansión de parámetros**.

```bash
while true; do
  read w
  # Lectura de la palabra

  [[ $w == "fin" ]] && break
  # Salida del bucle

  lower=${w,,}
  # Normalización a minúsculas

  reversed=""
  # Variable donde construiremos la cadena invertida

  for (( i=${#lower}-1; i>=0; i-- )); do
    reversed+="${lower:i:1}"
    # ${var:pos:len} extrae un carácter concreto de la cadena
  done

  if [[ $lower == $reversed ]]; then
    echo "$w -> Sí"
  else
    echo "$w -> No"
  fi
done
```

#### Comentarios técnicos
- No usa ningún comando externo
- Total control del algoritmo
- Ideal para evaluar:
  - bucles
  - índices
  - manipulación de cadenas

## 11. Número más frecuente
```bash
read -a nums
declare -A freq
for n in "${nums[@]}"; do (( freq[$n]++ )); done
max_num=
max_count=0
for k in "${!freq[@]}"; do
  if (( freq[$k] > max_count )); then
    max_count=${freq[$k]}
    max_num=$k
  fi
done
echo "$max_num"
```

## 13. Encuesta de edades
```bash
ages=()
while true; do
  read a
  [[ $a == "fin" ]] && break
  ages+=($a)
done

sum=0
max=${ages[0]}
min=${ages[0]}
maj=0

for x in "${ages[@]}"; do
  sum=$((sum+x))
  (( x>max )) && max=$x
  (( x<min )) && min=$x
  (( x>=18 )) && maj=$((maj+1))
done

echo "Media: $((sum/${#ages[@]}))"
echo "Max: $max"
echo "Min: $min"
echo "Mayores: $maj"
```
