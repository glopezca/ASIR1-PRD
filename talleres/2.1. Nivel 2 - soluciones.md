# 3.1. Nivel 2 - Soluciones (Entrada mediante readline)

Todas las soluciones usan **readline()** en lugar de `fgets(STDIN)`.

---

## 1. Imprimir una X de tamaño 10×10
```php
<?php
$size = 10;
for ($i = 0; $i < $size; $i++) {
    for ($j = 0; $j < $size; $j++) {
        echo ($i == $j || $i + $j == $size - 1) ? "x" : ".";
    }
    echo "
";
}
```

## 2. Triángulo numérico creciente
```php
<?php
$n = (int)readline();
for ($i = 1; $i <= $n; $i++) {
    for ($j = 1; $j <= $i; $j++) echo $j;
    echo "
";
}
```

## 3. Tabla de multiplicar completa
```php
<?php
for ($i = 1; $i <= 10; $i++) {
    for ($j = 1; $j <= 10; $j++) echo ($i*$j) . "\t";
    echo "
";
}
```

## 4. Matriz identidad
```php
<?php
$n = (int)readline();
for ($i = 0; $i < $n; $i++) {
    for ($j = 0; $j < $n; $j++) echo ($i == $j ? "1 " : "0 ");
    echo "
";
}
```

## 5. Contar cuántos números son primos
```php
<?php
$nums = array_map('intval', explode(" ", readline()));
$count = 0;

foreach ($nums as $n) {
    if ($n < 2) continue;
    $prime = true;
    for ($i = 2; $i <= sqrt($n); $i++) {
        if ($n % $i == 0) { $prime = false; break; }
    }
    if ($prime) $count++;
}
echo $count;
```

## 6. Cuadrado hueco
```php
<?php
$n = (int)readline();
for ($i = 0; $i < $n; $i++) {
    for ($j = 0; $j < $n; $j++) {
        echo ($i == 0 || $i == $n-1 || $j == 0 || $j == $n-1) ? "#" : " ";
    }
    echo "\n";
}
```

## 7. Rotación circular de lista
```php
<?php
$nums = explode(" ", readline());
$m = (int)readline();
$len = count($nums);

for ($i = 0; $i < $m; $i++) {
    $last = array_pop($nums);
    array_unshift($nums, $last);
}
echo implode(" ", $nums);
```

## 8. Sumar columnas de una matriz
```php
<?php
$n = (int)readline();
$m = (int)readline();
$sums = array_fill(0, $m, 0);

for ($i = 0; $i < $n; $i++) {
    $row = array_map('intval', explode(" ", readline()));
    for ($j = 0; $j < $m; $j++) $sums[$j] += $row[$j];
}
echo implode(" ", $sums);
```

## 9. Detectar palíndromos
```php
<?php
while (($w = trim(readline())) !== "fin") {
    $pal = strtolower($w) == strrev(strtolower($w));
    echo "$w -> " . ($pal ? "Sí" : "No") . "\n";
}
```

## 10. Tablero de ajedrez 8×8
```php
<?php
for ($i = 0; $i < 8; $i++) {
    for ($j = 0; $j < 8; $j++) {
        echo (($i + $j) % 2 == 0) ? "#" : ".";
    }
    echo "\n";

```

## 11. Número más frecuente
```php
<?php
$nums = explode(" ", readline());
$freq = [];

foreach ($nums as $n) $freq[$n] = ($freq[$n] ?? 0) + 1;

$max_num = null;
$max_count = -1;

foreach ($freq as $n => $c) {
    if ($c > $max_count) { $max_count = $c; $max_num = $n; }
}

echo $max_num;
```

## 12. Máquina de cambio
```php
<?php
$amount = (int)readline();
$coins = [50,20,10,5,2,1];

foreach ($coins as $c) {
    $count = intdiv($amount, $c);
    echo "$c: $count
";
    $amount %= $c;
}
```

## 13. Encuesta de edades
```php
<?php
$ages = [];
while (true) {
    $line = trim(readline());
    if ($line == "fin") break;
    $ages[] = (int)$line;
}

echo "Media: " . array_sum($ages)/count($ages) . "\n";
echo "Max: " . max($ages) . "\n";
echo "Min: " . min($ages) . "\n";

$count = 0;
foreach ($ages as $a) if ($a >= 18) $count++;
echo "Mayores de edad: $count";
```

## 14. Suma de matrices
```php
<?php
$n = (int)readline();
$m = (int)readline();
$A = $B = [];

for ($i = 0; $i < $n; $i++) $A[$i] = explode(" ", readline());
for ($i = 0; $i < $n; $i++) $B[$i] = explode(" ", readline());

for ($i = 0; $i < $n; $i++) {
    for ($j = 0; $j < $m; $j++) echo ($A[$i][$j] + $B[$i][$j]) . " ";
    echo "\n";
}
```

## 15. Pirámide invertida
```php
<?php
$n = (int)readline();
for ($i = $n; $i >= 1; $i--) echo str_repeat("*", $i) . "\n";
```

## 16. Patrón con “X” cada 3 posiciones

$size = (int)readline();
for ($i = 0; $i < $size; $i++) {
    for ($j = 0; $j < $size; $j++) echo ($j % 3 == 2) ? "X" : ".";

$mat = [];

## 18. Frecuencia de palabras
```php
<?php
$text = "";
while (($line = trim(readline())) !== "fin") $text .= " " . strtolower($line);

$words = explode(" ", trim($text));
$freq = [];

foreach ($words as $w) {
    if ($w === "") continue;
    $freq[$w] = ($freq[$w] ?? 0) + 1;
}

foreach ($freq as $w => $c) echo "$w: $c
";
```

## 19. Contraseñas aleatorias múltiples
```php
<?php
$cant = (int)readline();
$len = (int)readline();
$chars = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789";

for ($i = 0; $i < $cant; $i++) {
    $pwd = "";
    for ($j = 0; $j < $len; $j++)
        $pwd .= $chars[rand(0, strlen($chars)-1)];
    echo $pwd . "\n";
}
```

## 20. Contar dígitos en un número
```php
<?php
$num = trim(readline());
$count = array_fill(0, 10, 0);

foreach (str_split($num) as $d)
    if (ctype_digit($d)) $count[$d]++;

for ($i = 0; $i < 10; $i++) echo "$i: {$count[$i]}\n";
```
