# Soluciones en PHP para 20 ejercicios (readline, STDIN/STDOUT)

A continuación se incluyen soluciones en PHP para los 20 ejercicios, cada una pensada para resolverse en menos de 100 líneas y usando únicamente entrada estándar y salida estándar mediante **readline()**.

---

## 1. Suma de dos números
```php
<?php
$a = (int)readline();
$b = (int)readline();
echo $a + $b;
```

## 2. Contador de vocales
```php
<?php
$str = strtolower(trim(readline()));
$count = 0;
foreach (str_split($str) as $c) {
    if (in_array($c, ['a','e','i','o','u'])) $count++;
}
echo $count;
```

## 3. Números pares e impares
```php
<?php
$n = (int)readline();
for ($i = 1; $i <= $n; $i++) {
    echo $i . ($i % 2 == 0 ? " par\n" : " impar\n");
}
```

## 4. Tabla de multiplicar
```php
<?php
$n = (int)readline();
for ($i = 1; $i <= 10; $i++) {
    echo "$n x $i = " . ($n*$i) . "\n";
}
```

## 5. Calculadora básica
```php
<?php
$a = (float)readline();
$b = (float)readline();
$op = trim(readline());

switch ($op) {
    case '+': echo $a + $b; break;
    case '-': echo $a - $b; break;
    case '*': echo $a * $b; break;
    case '/': echo $b != 0 ? $a / $b : "Error: división por cero"; break;
    default: echo "Operación no válida";
}
```

## 6. Conversor de temperatura
```php
<?php
$val = (float)readline();
$unit = strtoupper(trim(readline()));

if ($unit == "C") echo ($val * 9/5 + 32) . " F";
else if ($unit == "F") echo (($val - 32) * 5/9) . " C";
else echo "Unidad no válida";
```

## 7. Inversión de cadena
```php
<?php
echo strrev(trim(readline()));
```

## 8. Determinar si es primo
```php
<?php
$n = (int)readline();
if ($n < 2) { echo "No primo"; exit; }

for ($i = 2; $i <= sqrt($n); $i++) {
    if ($n % $i == 0) { echo "No primo"; exit; }
}
echo "Primo";
```

## 9. Media de una lista
```php
<?php
$nums = array_map('floatval', explode(" ", trim(readline())));
echo array_sum($nums) / count($nums);
```

## 10. Frecuencia de caracteres
```php
<?php
$str = trim(readline());
$freq = [];
foreach (str_split($str) as $c) {
    $freq[$c] = ($freq[$c] ?? 0) + 1;
}
foreach ($freq as $c => $f) echo "$c : $f\n";
```

## 11. Máximo y mínimo
```php
<?php
$nums = array_map('floatval', explode(" ", trim(readline())));
echo "Max: " . max($nums) . "\nMin: " . min($nums);
```

## 12. Contador de palabras
```php
<?php
$str = trim(readline());
echo str_word_count($str);
```

## 13. Conversor de segundos
```php
<?php
$s = (int)readline();
$h = intdiv($s, 3600);
$m = intdiv($s % 3600, 60);
$sec = $s % 60;
echo "$h h $m m $sec s";
```

## 14. Número aleatorio entre límites
```php
<?php
$min = (int)readline();
$max = (int)readline();
echo rand($min, $max);
```

## 15. Cifrado César
```php
<?php
$txt = trim(readline());
$shift = (int)readline();
$res = "";

foreach (str_split($txt) as $c) {
    if (ctype_alpha($c)) {
        $base = ctype_upper($c) ? 'A' : 'a';
        $res .= chr((ord($c) - ord($base) + $shift) % 26 + ord($base));
    } else $res .= $c;
}
echo $res;
```

## 16. Ordenar números
```php
<?php
$nums = array_map('floatval', explode(" ", trim(readline())));
sort($nums);
echo implode(" ", $nums);
```

## 17. Validación de contraseña
```php
<?php
$pwd = trim(readline());
$ok = strlen($pwd) >= 8 &&
      preg_match("/[A-Z]/", $pwd) &&
      preg_match("/[a-z]/", $pwd) &&
      preg_match("/[0-9]/", $pwd);

echo $ok ? "Válida" : "Inválida";
```

## 18. Contador de líneas
```php
<?php
$count = 0;
while (true) {
    $line = trim(readline());
    if ($line === "") break;
    $count++;
}
echo $count;
```

## 19. Simulación de dado
```php
<?php
echo "Pulsa Enter para lanzar (vacío para salir)\n";
while (trim(readline()) !== "") {
    echo rand(1,6) . "\n";
}
```

## 20. Decimal a binario
```php
<?php
$n = (int)readline();
echo decbin($n);
```
