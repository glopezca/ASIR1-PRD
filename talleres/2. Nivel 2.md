# 20 Ejercicios de Programación con Bucles y Bucles Anidados (ASIR)

Ejercicios diseñados para alumnos de 1º de ASIR. Todos se pueden resolver usando PHP con entrada y salida estándar, y requieren bucles o bucles anidados.

---

## 1. Imprimir una X de tamaño 10×10
Dibuja una cuadrícula de 10×10 donde se muestre una “X” formada por caracteres `x`, usando bucles anidados.

---

## 2. Triángulo numérico creciente
Dado un número N, imprime un triángulo como:
```
1
12
123
1234
...
```

---

## 3. Tabla de multiplicar completa (1–10)
Genera la tabla de multiplicar del 1 al 10 usando dos bucles anidados.

---

## 4. Matriz identidad de tamaño N
Imprime una matriz identidad usando bucles anidados:
```
1 0 0
0 1 0
0 0 1
```

---

## 5. Contar cuántos números de una lista son primos
El usuario introduce una serie de números separados por espacios. El programa calcula cuántos son primos usando bucles.

---

## 6. Dibujar un cuadrado hueco
El usuario introduce el tamaño N y el programa dibuja un cuadrado con borde de `#` y el interior vacío.

---

## 7. Rotación circular de una lista
Pide una lista de números y rota sus posiciones hacia la derecha M veces usando bucles.

---

## 8. Sumar columnas de una matriz
El usuario introduce valores fila por fila. El programa calcula la suma de cada columna mediante bucles anidados.

---

## 9. Detectar palíndromos en un conjunto de palabras
Lee varias palabras (una por línea) y muestra cuáles son palíndromos.

---

## 10. Generar un tablero de ajedrez 8×8
Imprime un patrón como:
```
# . # .
. # . #
...
```
Usando bucles anidados para alternar caracteres.

---

## 11. Buscar el número más frecuente
Dada una lista de números, encuentra el número que aparece más veces utilizando únicamente bucles (no funciones automáticas de conteo).

---

## 12. Simular una máquina de cambio
El usuario introduce una cantidad en céntimos. Calcula cuántas monedas de 50, 20, 10, 5, 2 y 1 céntimo debe devolver usando bucles.

---

## 13. Encuesta de edades
Se piden edades hasta que el usuario escriba “fin”. El programa muestra:
- Media  
- Máxima  
- Mínima  
- Cuántos son mayores de edad  

---

## 14. Sumar dos matrices N×M
Pide dos matrices de igual tamaño y suma sus elementos usando bucles anidados.

---

## 15. Generar una pirámide invertida
Ejemplo para N = 5:
```
*****
****
***
**
*
```

---

## 16. Imprimir un patrón tipo tablero con “X” cada 3 posiciones
Ejemplo (10×10):
```
..X..X..X..
..X..X..X..
...
```

---

## 17. Matriz transpuesta
Dada una matriz N×M, calcula su transpuesta usando bucles anidados.

---

## 18. Analizar texto y mostrar la frecuencia de cada palabra
Cuenta cuántas veces aparece cada palabra en un texto introducido por varias líneas.  
Debe ignorar mayúsculas y minúsculas.

---

## 19. Generar contraseñas aleatorias múltiples
El usuario introduce cuántas contraseñas quiere y de qué longitud.  
Debe usar un bucle externo para generar cada contraseña y uno interno para construirla carácter a carácter.

---

## 20. Contar cuántas veces aparece cada dígito en un número grande
Ejemplo:
Entrada:
```
12955122111
```
Salida:
```
0: 0 veces
1: 5 veces
2: 3 veces
3: 0 veces
...
9: 1 vez
```
Debe resolverse mediante bucles (sin funciones automáticas de conteo).
